# Code of Conduct

## Our pledge

We want tenantbleed to be a welcoming, harassment-free project for everyone, regardless of
experience, background or identity.

## Our standards

Be respectful and constructive. Assume good faith. Focus on the technical merits. Not
acceptable: harassment, personal attacks, discriminatory or demeaning comments, and sharing
others' private information.

Because this is a security tool, one more rule matters: do not post findings, data, or
proof-of-concept exploits from applications you do not own. Use the planted fixtures and
neutral examples.

## Scope and enforcement

This applies in all project spaces (issues, pull requests, discussions). Report unacceptable
behavior privately to the maintainer through a GitHub Security Advisory or a direct message.
Maintainers may remove, edit or reject contributions that violate this code, and may ban
repeat offenders.

This Code of Conduct is adapted from the spirit of the Contributor Covenant.
